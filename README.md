# CS2680 现代 AI 系统 · 中文课件

哈佛大学 SEAS《CS2680 Modern AI Systems: Agents and System Optimizations》（2026 秋季，讲师 Juncheng Yang）课件的**非官方中文译本**，原版课件见 <https://cs2680.com>。

在线阅读：<https://zhangyiling108-code.github.io/cs2680-zh/>

## 内容

- `index.html`：课程总览
- `lectures/`：13 讲课件 + A3 作业说明，每页支持「对照 / 中文 / 原版」三种显示模式
- `assets/slides/`：原版课件页面截图
- `_src/`：中文 Markdown 源稿与生成脚本（`python3 _src/build.py`）
