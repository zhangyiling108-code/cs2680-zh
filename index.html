CS2680 现代 AI 系统
智能体与系统优化

Modern AI Systems: Agents and System Optimizations

这门课沿着同一个智能体系统，从智能体循环一路向下贯穿到推理服务栈。 你先使用一个现代编程智能体（Claude Code），再利用提供的 API 设计你自己的智能体，测量它、优化它； 然后亲手部署一个开放权重模型，并为其下面的各层负责：批处理与调度、KV-cache 与前缀复用、路由、量化与推测解码。

先修CS61 + 至少一门研究生级计算机系统课；熟悉 Python 与 PyTorch
考核5 个作业 + 期末项目 + 课堂参与，无考试
上课周一、周三 11:15–12:30 · SEC LL2.229

五个作业：沿技术栈逐层向下

  1. Mads-Lens看智能体如何工作 10%
  2. Mads-Loop亲手搭建智能体循环 10%
  3. Mads-Opt让每个 token 都物有所值 20%
  4. Mads-Serve掌控推理服务引擎 20%
  5. Mads-Stack优化整个技术栈 10%

“Mads” 是 Modern Agent Design and Systems（现代智能体设计与系统）的缩写，也致敬了开设本课的哈佛 MaDSys 研究组。 课程期望：这门课不会教会你完成作业所需的每一个知识点，而是专注于“学习的技能”，并为你指出值得探索的方向——请预期课后要花大量时间自学与实验。
